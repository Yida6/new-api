# JadeRoute brand direction

## Brand name

**JadeRoute**

- **Jade** signals Chinese origin through a premium, internationally familiar cultural reference without putting a country label in the product name.
- **Route** describes the product's core value: one gateway that routes requests across models and providers.
- The name is short, pronounceable, and works naturally in product extensions such as JadeRoute Console, JadeRoute API, and JadeRoute Cloud.

## Positioning

**Category:** AI API gateway for global developers

**Tagline:** China's leading AI models. One global API.

**Supporting line:** Connect DeepSeek, Qwen, Doubao, GLM, Kimi, and more through one production-ready endpoint.

**Short descriptor:** Global access to leading Chinese AI models.

## Logo concept

The icon combines three ideas:

1. An open gateway for simple access.
2. A curved route that subtly suggests the letter J.
3. A violet endpoint representing a model selected by the routing layer.

The production SVG uses only three geometric elements so it remains legible as a favicon and can be reproduced reliably across the website, console, documentation, and social profiles.

## Usage

- Use **JadeRoute** as one word with capital J and R.
- Use the standalone mark for favicons, app icons, and compact navigation.
- Pair the mark with a clean sans-serif wordmark for full navigation and marketing use.
- Keep at least one-quarter of the icon width as clear space around the mark.
- Do not add flags, dragons, globes, or model-provider logos to the core mark.
